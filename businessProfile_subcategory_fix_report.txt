BUSINESS PROFILE SUBCATEGORY FIX REPORT
======================================

1. SUMMARY OF THE ISSUE
----------------------
The mobile application was sending the field name "subCategory" to the backend during business profile creation and updates, but the backend expects "businessSubcategory". This mismatch caused the backend to store the business subcategory as an empty value.

2. ROOT CAUSE
------------
- Service layer (businessProfile.ts) was mapping frontend data to backend payload using incorrect field name
- createBusinessProfile() function used: subCategory: data.subCategory || data.subcategory
- updateBusinessProfile() function used: backendData.subCategory = data.subCategory
- Backend API expects: businessSubcategory

3. FILES MODIFIED
-----------------
- src/services/businessProfile.ts

4. CODE CHANGES MADE
-------------------

A. Interface Update (CreateBusinessProfileData)
BEFORE:
export interface CreateBusinessProfileData {
  name: string;
  description?: string;
  category: string;
  subCategory?: string;            // User's selected subcategory during registration
  subcategory?: string;            // Alternative field name for consistency
  // ... other fields
}

AFTER:
export interface CreateBusinessProfileData {
  name: string;
  description?: string;
  category: string;
  businessSubcategory?: string;    // User's selected subcategory during registration (NEW FIELD)
  subCategory?: string;            // User's selected subcategory during registration (LEGACY)
  subcategory?: string;            // Alternative field name for consistency (LEGACY)
  // ... other fields
}

B. createBusinessProfile() Function (Line 301-321)
BEFORE:
const backendData = {
  businessName,
  ownerName,
  email,
  phone,
  address,
  category,
  subCategory: data.subCategory || data.subcategory,
  logo: logoUrl,
  companyLogo: logoUrl,
  description: data.description || '',
  website: data.website || ''
};

AFTER:
const resolvedSubcategory =
  data.businessSubcategory ||
  data.subCategory ||
  data.subcategory ||
  '';

const backendData = {
  businessName,
  ownerName,
  email,
  phone,
  address,
  category,
  businessSubcategory: resolvedSubcategory,
  logo: logoUrl,
  companyLogo: logoUrl,
  description: data.description || '',
  website: data.website || ''
};

console.log("Final Backend Payload:", backendData);

C. updateBusinessProfile() Function (Line 409-412)
BEFORE:
if (data.subCategory !== undefined) backendData.subCategory = data.subCategory;
if (data.subcategory !== undefined) backendData.subCategory = data.subcategory;

AFTER:
// Handle subcategory field with backward compatibility
if (data.businessSubcategory !== undefined) backendData.businessSubcategory = data.businessSubcategory;
else if (data.subCategory !== undefined) backendData.businessSubcategory = data.subCategory;
else if (data.subcategory !== undefined) backendData.businessSubcategory = data.subcategory;
