### STEP 2: Safe Helper Function (CREATED)

**Location:** PosterEditorScreen.tsx lines 2654-2667

```typescript
const getEffectiveBusinessSubscription = () => {
  const businessStatus = selectedBusinessProfile?.businessSubscriptionStatus;
  
  if (businessStatus) {
    return businessStatus.toLowerCase() === "active";
  }
  
  // Fallback for safety
  return (
    selectedBusinessProfile?.subscriptionStatus?.toUpperCase() === "ACTIVE" ||
    isSubscriptionActive
  );
};
```

**Features:**
- Primary: businessSubscriptionStatus validation
- Fallback 1: subscriptionStatus validation  
- Fallback 2: isSubscriptionActive context
- Case-insensitive comparison
