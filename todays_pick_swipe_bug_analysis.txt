====================================
TODAY'S PICK SCREEN SWIPE BUG ANALYSIS
====================================

PROBLEM DESCRIPTION
==================

When a user swipes the main image to change the poster in the Today's Pick screen, 
the images inside the Preview Grid automatically vanish/disappear. This should not happen - 
the preview grid should retain all images unless explicitly removed by the user.

====================================
FEATURE ARCHITECTURE OVERVIEW
==============================

The Today's Pick screen consists of two main components:

1. MAIN POSTER VIEWER (Top Section)
   - Displays current selected poster in full size
   - Supports swipe gestures (left/right) to navigate between posters
   - Uses PanResponder for gesture handling
   - Updates currentPoster state on swipe

2. PREVIEW GRID (Bottom Section) 
   - FlatList displaying all available posters in a grid layout
   - Shows filtered posters based on selected language
   - Uses filteredPosters array as data source
   - Highlights currently selected poster

==================

Initial State:
├── todayPosters: Template[] (all today's posters)

====================================
WHERE THE IMAGE ARRAY BECOMES EMPTY
===================================

ROOT CAUSE IDENTIFIED:

The issue occurs because todayPosters array is being CLEARED during category/calendar 
change operations, but the swipe action doesn't properly restore it.

Evidence from code:

1. MULTIPLE CLEAR OPERATIONS (Lines 1287, 1350, 1425, 1677, 1818):
```typescript
// Clear allTemplates immediately to prevent showing old posters in grid
setAllTemplates([]);
```

2. MISSING todayPosters SYNC:
   - When allTemplates is cleared, todayPosters is NOT properly restored
   - filteredPosters becomes empty because todayPosters is empty
   - FlatList receives empty array and shows no images

3. STATE INCONSISTENCY:
   - allTemplates and todayPosters should stay synchronized
   - Clear operations only affect allTemplates
   - todayPosters remains in inconsistent state

====================================
ROOT CAUSE OF THE ISSUE
========================

PRIMARY ROOT CAUSE:
State synchronization failure between allTemplates and todayPosters arrays.

DETAILED EXPLANATION:

1. NORMAL OPERATION:
   - todayPosters loaded from API/cache (line 1152: setTodayPosters(orderedPosters))
   - allTemplates synced with todayPosters (line 1156: setAllTemplates(templatesWithLanguages))
   - filteredPosters derived from todayPosters (line 1178-1194)
   - Grid displays correctly

2. CATEGORY/CALENDAR CHANGE:
   - allTemplates cleared: setAllTemplates([]) (multiple locations)
   - todayPosters NOT properly restored
   - filteredPosters becomes empty (derived from empty todayPosters)
   - Grid shows no images

3. SWIPE ACTION TRIGGER:
   - User swipes → handlePosterSelect() called
   - filteredPosters recalculated from empty todayPosters
   - FlatList receives empty array
   - Images disappear from grid

4. WHY IT HAPPENS ON SWIPE:
   - Swipe triggers handlePosterSelect()
   - This causes filteredPosters useMemo to recalculate
   - Empty todayPosters results in empty filteredPosters
   - Grid re-renders with empty data

====================================
CONCLUSION
===========

The Today's Pick screen swipe bug is caused by a state synchronization issue where 
todayPosters array becomes desynchronized from allTemplates during category/calendar 
change operations. When users swipe, the filteredPosters derivation uses the empty 
todayPosters array, causing the preview grid to show no images.

The fix requires ensuring proper state synchronization and adding defensive programming 
to prevent empty state scenarios during user interactions.
