LOGIN SCREEN - VALID LOGIN TEST CASES
=====================================

Test Case ID: LOGIN-VALID-001
Test Case Title: Successful login with valid credentials
Preconditions:
- User has valid registered account
- App is launched and login screen is displayed
- Network connection is available
Test Steps:
1. Launch the application
2. Navigate to login screen (if not already there)
3. Enter valid email address in email input field (testID: email-input)
4. Enter valid password in password input field (testID: password-input)
5. Verify "Remember me" checkbox is unchecked (testID: remember-me-checkbox)
6. Tap "Sign In" button (testID: sign-in-button)
Test Data:
- Email: user@example.com
- Password: Password123
Expected Result:
- Loading indicator appears (testID: loading-indicator)
- User is successfully authenticated
- User is redirected to home/dashboard screen
- No error modal is displayed
- User session is established
