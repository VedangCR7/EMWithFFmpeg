LOGIN SCREEN - INVALID LOGIN TEST CASES
======================================

Test Case ID: LOGIN-INVALID-001
Test Case Title: Login with empty email and password fields
Preconditions:
- App is launched and login screen is displayed
- Network connection is available
Test Steps:
1. Launch the application
2. Navigate to login screen
3. Leave email field empty (testID: email-input)
4. Leave password field empty (testID: password-input)
5. Tap "Sign In" button (testID: sign-in-button)
Test Data:
- Email: (empty)
- Password: (empty)
Expected Result:
- Validation error appears for email field: "Email is required"
- Validation error appears for password field: "Password is required"
- Error modal appears with message: "Please fix the validation errors"
- No API call is made to server
- User remains on login screen
