=======================================

Test Case ID: LOGIN-EDGE-001
Test Case Title: SQL Injection attempt in email field
Preconditions:
- App is launched and login screen is displayed
- Network connection is available
Test Steps:
1. Launch the application
2. Navigate to login screen
3. Enter SQL injection string in email field (testID: email-input)
4. Enter valid password in password field (testID: password-input)
5. Tap "Sign In" button (testID: sign-in-button)
Test Data:
- Email: ' OR '1'='1' --
- Password: Password123
Expected Result:
- Input sanitization removes dangerous characters
- Sanitized input is safe for API call
- Loading indicator appears (testID: loading-indicator)
- Server rejects malicious input
- Error modal appears with appropriate error message
- No SQL injection vulnerability is exploited
