## 4. API Integration Details

### Backend API Integration:
- **Endpoint**: `POST /api/mobile/feedback`
- **Service**: Uses existing `api` service from `src/services/api.ts`
- **Request Payload**:
  ```typescript
  {
    resourceType: "APP_GENERAL",
    rating: number, // 1-5 stars
    feedbackText: string, // User's feedback text (max 2000 chars)
    feedbackCategory: string // Selected category value
  }
  ```
- **Authentication**: JWT token automatically included via api interceptor
- **Error Handling**: Comprehensive error handling with user-friendly messages

## 5. UI Components Used

### FeedbackScreen Components:
- **Star Rating**: Interactive 5-star rating system with MaterialIcons
- **Category Dropdown**: Custom dropdown with 4 categories:
  - Bug Report (BUG_REPORT)
  - Feature Request (FEATURE_REQUEST)
  - User Experience (USER_EXPERIENCE)
  - General Feedback (GENERAL_FEEDBACK)
- **Text Input**: Multiline TextInput with 2000 character limit
- **Submit Button**: Loading state with ActivityIndicator
- **Header**: Custom header with back button

### Design Consistency:
- Uses existing theme context for colors and styling
- Responsive design matching other screens
- Consistent spacing and typography
- Material Icons integration

## 6. Validation Rules

### Form Validation:
1. **Rating Required**: User must select 1-5 stars
2. **Category Required**: User must select a feedback category
3. **Feedback Text Required**: Text cannot be empty
4. **Character Limit**: Feedback text limited to 2000 characters
5. **Real-time Character Count**: Shows current/2000 characters

### Validation Messages:
- "Please select a rating"
- "Please select a feedback category"
- "Please enter your feedback"
- "Feedback text cannot exceed 2000 characters"

## 7. Success/Error Handling

### Success Handling:
- Shows success alert: "Thank you for your feedback! We appreciate your input."
- Clears form data (rating, category, text)
- Navigates back to ProfileScreen automatically

### Error Handling:
- Network errors: "Failed to submit feedback. Please try again."
- Server errors: Displays server error message if available
- Validation errors: Specific validation messages
- Loading state: Disables submit button and shows ActivityIndicator

## 8. User Flow Implementation

### Complete User Journey:
1. **Profile Screen** 
   - User taps "Feedback" menu item in Support & Legal section
2. **Feedback Screen Opens**
   - Screen loads with empty form
   - Header shows "Submit Feedback" with back button
3. **User Interaction**
   - Taps stars to select rating (1-5)
   - Taps dropdown to select category
   - Types feedback in multiline text input
   - Sees real-time character count
4. **Submission**
   - Taps "Submit Feedback" button
   - Form validation runs
   - Loading state shows during API call
5. **Result**
   - Success: Alert shown, form cleared, returns to Profile
   - Error: Error alert shown, user can retry
