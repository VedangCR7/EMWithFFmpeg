7. ROOT CAUSE SUMMARY
----------------------------------------
Primary issue: Data source inconsistency between route parameters and context state. The validation compares categoryName (static from navigation) with selectedBusinessCategory (dynamic from context). When business profile changes in context, the route params don't update, causing validation failures even when data is actually consistent.

Secondary issue: Subscription status complexity with multiple fields, formats, and fallback logic creates unpredictable validation behavior. The helper function attempts to reconcile different data sources but introduces ambiguity.

The validation logic is fundamentally flawed because it assumes data synchronization between independent data stores (navigation params vs context state) without any reconciliation mechanism.
