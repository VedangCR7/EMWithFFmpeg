POSTER NAVIGATION BUSINESS VALIDATION ANALYSIS
================================================

1. SYSTEM OVERVIEW
----------------

The mobile application implements a Business Category Poster Generator Flow with navigation:
HomeScreen → PosterPlayerScreen → PosterEditorScreen → PosterPreviewScreen

A business validation rule must be enforced before navigating from PosterEditorScreen to PosterPreviewScreen:
- User can proceed only if: selectedBusinessProfile.category == clickedBusinessCategory AND selectedBusinessProfile.subscriptionStatus == "ACTIVE"
- Otherwise, redirect to BusinessProfilesScreen

2. NAVIGATION GRAPH
-----------------

HomeScreen
├──→ PosterPlayerScreen (with businessCategory parameter)
│   ├──→ PosterEditorScreen (with selectedBusinessProfile)
│   │   ├──→ PosterPreviewScreen (if validation passes)
│   │   └──→ BusinessProfilesScreen (if validation fails)
│   └──→ [Back to HomeScreen]
└──→ [Other navigation paths]

Navigation Library: React Navigation with Stack Navigator
Navigation Types: Defined in src/navigation/types.ts (MainStackParamList)

BusinessProfile Structure:
```typescript
interface BusinessProfile {
  id: string;
  name: string;
  description: string;
  category: string;              // KEY: Business category
  subCategory?: string;
  address: string;

  updatedAt: string;
}
```

10. EDGE CASES
--------------

Case 1: No Business Profile Selected
- Detection: activeBusinessProfile is null/undefined
- Handling: Navigate to BusinessProfilesScreen

Case 2: Subscription Expired
- Detection: subscriptionStatus !== "ACTIVE"
- Handling: Navigate to BusinessProfilesScreen

Case 3: Category Mismatch
- Detection: profileCategory !== clickedCategory
- Handling: Navigate to BusinessProfilesScreen

Case 4: Multiple Profiles
- Detection: Context provides selected profile
- Handling: Use currently selected profile from context

Case 5: Navigation Param Undefined
- Detection: clickedCategory is undefined
- Handling: Navigate to BusinessProfilesScreen
