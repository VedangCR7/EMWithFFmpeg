2. SUBSCRIPTION WORKFLOW ANALYSIS
=================================

Complete Subscription Purchase Flow:

Step 1: User selects subscription plan
   - Screen: SubscriptionScreen.tsx
   - Action: User taps "Subscribe" button
   - Function: handlePayment()

Step 2: Create payment order
   - Service: subscriptionApi.createPaymentOrder()
   - Endpoint: POST /api/mobile/subscriptions/create-order
   - Payload: { planId, amount, currency }
   - Response: { orderId, amount, razorpayKey }

Step 3: Initialize Razorpay modal
   - Package: react-native-razorpay
   - Configuration: Order ID, amount, user details, UPI apps only
   - Method: RazorpayCheckout.open(options)

Step 4: Payment success callback
   - Action: Record transaction via addTransaction()
   - Service: subscriptionApi.verifyPayment()
   - Endpoint: POST /api/mobile/subscriptions/verify-payment
   - Payload: { orderId, paymentId, signature, amount, planId }

Step 5: Activate subscription
   - Service: subscriptionApi.subscribe()
   - Endpoint: POST /api/mobile/subscriptions/subscribe
   - Payload: { planId, paymentMethod, autoRenew }

Step 6: Update UI state
   - Context: SubscriptionContext
   - Actions: setIsSubscribed(true), refreshSubscription()

Payment Failure Handling:
   - Razorpay modal close events handled
   - Failed transactions recorded with status 'failed'
   - Error modal displayed to user
   - No backend status update for failures
