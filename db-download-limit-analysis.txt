## 2. DOWNLOAD TABLES ANALYSIS

### 2.1 Primary Download Table: MobileDownload
```prisma
model MobileDownload {
  id           String     @id @default(cuid())
  mobileUserId String
  resourceType String
  resourceId   String
  fileUrl      String
  downloadedAt DateTime   @default(now())
  createdAt    DateTime   @default(now())
  mobile_users MobileUser @relation(fields: [mobileUserId], references: [id])

  @@map("mobile_downloads")
}
```

**Column Analysis:**
- **id**: Primary Key (String, CUID format)
- **mobileUserId**: Foreign Key to MobileUser (String)
- **resourceType**: Enum-like String (TEMPLATE, VIDEO, GREETING, CONTENT, POSTER, CALENDAR)
- **resourceId**: String identifier for the downloaded resource
- **fileUrl**: String URL of the downloaded file
- **downloadedAt**: DateTime with default now() - **CRITICAL FOR DAILY LIMITS**
- **createdAt**: DateTime with default now()

**Foreign Keys:**
- **mobileUserId** → MobileUser.id

**Indexes:**
- **Primary Key**: id (implicit)
- **No explicit indexes** on mobileUserId, resourceType, or downloadedAt
