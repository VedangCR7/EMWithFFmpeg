FORMDATA IMPLEMENTATION DETAILS
================================

createBusinessProfile:
----------------------
1. Check if logoUri is a local file path using isLocalFilePath()
2. If local file path:
   - Create FormData object
   - Append all required fields (businessName, ownerName, email, phone, address, category)
   - Append optional fields (description, website, alternatePhone, businessSubcategory)
   - Append logo file with proper MIME type (jpg, png, gif, webp)
   - Send POST request with Content-Type: multipart/form-data
3. If URL or empty:
   - Create JSON object with all fields
   - Send POST request with Content-Type: application/json
4. Parse response and prioritize businessLogo field

updateBusinessProfile:
----------------------
1. Check if logoUri is a local file path using isLocalFilePath()
2. If local file path:
   - Create FormData object
   - Append provided fields only (partial update)
   - Append logo file with proper MIME type
   - Send PUT request with Content-Type: multipart/form-data
3. If URL or empty:
   - Create JSON object with provided fields only
   - Send PUT request with Content-Type: application/json
4. Parse response and prioritize businessLogo field

MIME TYPE HANDLING
==================
- jpg/jpeg: image/jpeg
- png: image/png
- gif: image/gif
- webp: image/webp

RESPONSE MAPPING
================
Logo URL priority order:
1. businessLogo (primary field from backend)
2. logo (legacy field)
3. companyLogo (alternative field)
4. profileLogo (alternative field)
5. image (alternative field)
6. photo (alternative field)
