MOBILE APP FLOW DOCUMENTATION
====================================

APP OVERVIEW
============

MarketBrand is a comprehensive mobile application for event marketing, poster creation, 
greeting cards, and video editing. It serves as an enterprise marketing suite for businesses 
and creators to manage their marketing content.

Main Purpose:
- Create and customize marketing posters and videos
- Manage business profiles and marketing campaigns  
- Browse and download template galleries
- Handle subscription payments and premium features
- Track downloaded content and manage user preferences

Target Users: Business owners, entrepreneurs, event planners, and marketers

====================================
USER JOURNEY
============

1. APP LAUNCH
   ↓
2. AUTHENTICATION CHECK
   ↓
3. MAIN APP NAVIGATION
   ↓

   ↓
5. CONTENT CREATION/DOWNLOAD
   ↓
6. SUBSCRIPTION MANAGEMENT
   ↓

====================================
SCREEN BY SCREEN FLOW
=====================

1. APP LAUNCH FLOW
------------------
User opens app
   ↓
Splash screen appears (2 seconds minimum)
   ↓
App checks if user is logged in (stored credentials)
   ↓
If logged in → Home Screen
If not logged in → Login Screen

2. LOGIN/AUTHENTICATION FLOW
----------------------------
Login Screen appears
   ↓
User enters mobile number and password
   ↓
App sends login request to backend server
   ↓
Server verifies credentials and returns authentication token
   ↓
App stores token and user information locally
   ↓
User is redirected to Home Screen

Alternative Login Options:
- Registration: New users can create account
- Forgot Password: Users can reset password via email/OTP

3. HOME SCREEN FLOW
-------------------
User enters Home Screen (main dashboard)
   ↓
App loads featured content from server:
   - Banners and promotional content
   - Featured posters and templates
   - Business categories
   - Calendar events
   ↓
User can:
   - Search for content by keywords
   - Browse different categories 
   - Switch between business profiles
   - Navigate to main sections via bottom tabs

4. MAIN NAVIGATION TABS
----------------------
The app has 5 main tabs:

HOME TAB
- Shows featured content and search
- Displays business profile switcher
- Shows calendar events and categories

TEMPLATES TAB
- Browse poster templates gallery
- Preview templates in grid view
- Access template editor

MY BUSINESS TAB
- View business-specific posters
- Manage business profiles
- Create business marketing content

GREETINGS TAB
- Browse greeting templates


PROFILE TAB
- Manage user account settings
- View subscription status
- Access transaction history
- Manage business profiles
- App settings and preferences

5. POSTER VIEWING FLOW
---------------------
User selects a poster from any gallery
   ↓
Poster Player Screen opens showing:
   - Full poster preview
   - Download button
   - Share button  
   - Edit button (for customization)
   ↓
User actions:
   - Download: Saves poster to device gallery
   - Share: Shares poster via social media/apps
   - Edit: Opens poster editor for customization
   - Back: Returns to previous gallery

6. POSTER EDITOR FLOW
---------------------
User clicks Edit on a poster
   ↓
Poster Editor Screen opens with:
   - Poster template loaded
   - Text editing tools
   - Color and font options
   - Business profile information
   - Save and export options
   ↓
User can:
   - Edit text content
   - Change fonts
   - Add business details
   - Preview changes in real-time
   - Save edited poster
   - Export to device gallery

7. DOWNLOAD FLOW
----------------
User clicks Download on any poster
   ↓
App checks subscription status
   ↓
App downloads poster to device gallery
   ↓
Download is tracked in user's download history
   ↓
User can view downloaded posters in "My Posters" section

8. SUBSCRIPTION FLOW
-------------------
User clicks Subscribe or tries premium feature
   ↓
Subscription Screen opens showing:
   - Available plans (Quarterly/Yearly)
   - Plan features and pricing
   - Current subscription status
   ↓
User selects a plan
   ↓
App opens Razorpay payment gateway
   ↓
User completes payment
   ↓
App verifies payment with server
   ↓
Subscription status is updated
   ↓
User gets access to premium features

9. BUSINESS PROFILE FLOW
------------------------
User accesses My Business section
   ↓
Business Profile Screen shows:
   - List of user's business profiles
   - Option to create new profile
   - Profile management options
   ↓
Create/Edit Business Profile:
   - Enter business name and details
   - Upload business logo
   - Select business category
   - Add contact information
   - Save profile to server

10. CALENDAR/EVENTS FLOW
------------------------
User browses calendar section
   ↓
App loads upcoming festivals and events
   ↓
Events are organized by date and category
   ↓
User can:
   - Find related posters for events
   - Download event-specific content
