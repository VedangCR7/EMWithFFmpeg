SUBCATEGORY BACK NAVIGATION FIX REPORT
====================================

DATE: 2026-03-09
OBJECTIVE: Fix back button navigation from subcategory pages to return to View More page instead of HomeScreen
STATUS: COMPLETED

============================================================
ORIGINAL ISSUE
============================================================

PROBLEM DESCRIPTION:
- User opens View More modal from HomeScreen (Business Categories, etc.)
- User clicks on a subcategory from the modal
- User navigates to PosterPlayer screen with subcategory content
- User presses back button
- CURRENT BEHAVIOR: Redirects to HomeScreen
- EXPECTED BEHAVIOR: Should redirect back to the View More modal/page

USER EXPERIENCE ISSUE:
- User loses context of the View More browsing
- User has to navigate back through multiple screens to reach View More again
- Inconsistent navigation behavior
- Poor user experience

============================================================
ROOT CAUSE ANALYSIS
============================================================

NAVIGATION FLOW:
1. HomeScreen → View More Modal (Business Categories, etc.)
2. View More Modal → Subcategory selection
3. Subcategory → PosterPlayer screen
4. PosterPlayer → Back button → HomeScreen (INCORRECT)

ISSUE IDENTIFICATION:
- handleBusinessCategoryPress() in HomeScreen navigates to PosterPlayer
- Navigation parameters include businessCategory, templateSource, etc.
- Missing: originScreen parameter to indicate navigation source
- PosterPlayer's handleBackPress() doesn't know to return to View More modal

EXISTING LOGIC:
- PosterPlayer already handles originScreen === 'GreetingTemplates'
- PosterPlayer navigates back to GreetingTemplates correctly
- Missing: originScreen === 'HomeScreen' handling

STEP 3 - ADD BACK NAVIGATION LOGIC:
In PosterPlayerScreen.tsx handleBackPress():

```typescript
// BEFORE:
const handleBackPress = useCallback(() => {
  if (originScreen === 'GreetingTemplates') {
    navigation.navigate('GreetingTemplates');
    return;
  }

  if (navigation.canGoBack()) {
    navigation.goBack();
  } else {
    navigation.navigate('MainTabs');
  }
}, [navigation, originScreen]);

// AFTER:
const handleBackPress = useCallback(() => {
  if (originScreen === 'GreetingTemplates') {
    navigation.navigate('GreetingTemplates');
    return;
  }

  if (originScreen === 'HomeScreen') {
    navigation.navigate('MainTabs', { screen: 'Home' });
    return;
  }

  if (navigation.canGoBack()) {
    navigation.goBack();
  } else {
    navigation.navigate('MainTabs');
  }
}, [navigation, originScreen]);
```
