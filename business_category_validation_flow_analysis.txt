6. EDGE CASES
---------------

**Possible problems and solutions:**

1. **Category Not Selected**
   - **Problem:** User navigates to PosterPlayerScreen without category selection
   - **Solution:** Default to empty string, skip validation, allow normal flow

2. **Poster Without Category**
   - **Problem:** Template object missing category field
   - **Solution:** Use fallback validation: if poster category missing, skip validation

3. **Category Mismatch Handling**
   - **Problem:** User gets stuck in validation loop
   - **Solution:** Add "Skip" option in validation alert, allow manual override

4. **Navigation Stack Issues**
   - **Problem:** Deep navigation stack causing back button issues
   - **Solution:** Use `navigation.replace()` instead of `navigate()` for validation redirect

5. **User Returning from BusinessProfileScreen**
   - **Problem:** How to handle back navigation after profile update
   - **Solution:** Pass return destination in params, use conditional navigation

6. **Multiple Profile Categories**
   - **Problem:** User has multiple business profiles with different categories
   - **Solution:** Validate against currently selected profile, allow profile switching

7. **Async Profile Loading**
   - **Problem:** Business profile not loaded when validation runs
   - **Solution:** Wait for profile loading or add loading state

8. **Network Issues**
   - **Problem:** Can't fetch updated profile data
   - **Solution:** Allow offline validation with cached data, show retry option
