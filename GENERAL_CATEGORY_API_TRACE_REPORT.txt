## 3. API DETAILS

### A. Categories API
- **Endpoint**: `/api/mobile/greetings/categories`
- **Method**: `GET`
- **Full URL**: `https://eventmarketersbackend.onrender.com/api/mobile/greetings/categories`
- **Payload**: None (GET request)
- **Cache TTL**: 5 minutes

### B. Template Preview API
- **Endpoint**: `/api/mobile/greetings/templates`
- **Method**: `GET` 
- **Full URL**: `https://eventmarketersbackend.onrender.com/api/mobile/greetings/templates?search={categoryName}&language=all&limit=1`
- **Payload**: Query parameters
  - `search`: Category name (e.g., "birthday", "wedding")
  - `language`: "all" (default)
  - `limit`: 1 (for preview images)
- **Cache TTL**: 5 minutes

### Implementation Details:
```typescript
// Line 193 - Categories API Call
const response = await api.get('/api/mobile/greetings/categories');

// Line 613 - Templates API Call
const response = await api.get(`/api/mobile/greetings/templates?${params.toString()}`);
```

## 7. FINAL CONCLUSION

### Exact API Responsible for General Category Images:

**PRIMARY API**: `/api/mobile/greetings/categories`
- **Purpose**: Fetches category list with metadata (id, name, icon, color)
- **Used for**: Category list rendering in GeneralCategoriesSection

**SECONDARY API**: `/api/mobile/greetings/templates`
- **Purpose**: Fetches template preview images for categories
- **Used for**: Category thumbnail images and template data

### Template ID Verification:
✅ **VALID IDs**: Backend provides proper template IDs  
✅ **NO TRANSFORMATION LOSS**: IDs preserved through entire flow  
✅ **CACHE FRIENDLY**: IDs stored in `greetingCategoryPreviews` for instant access  

### Key Findings:

1. **API Endpoints Identified**:
   - Categories: `GET /api/mobile/greetings/categories`
   - Templates: `GET /api/mobile/greetings/templates?search={category}&limit=1`

2. **Template ID Flow**:
   - Backend provides valid `id` field
   - Frontend maps directly: `id: backendTemplate.id`
   - No ID transformation or loss occurs

3. **Data Structure**:
   - Categories have `id`, `name`, `icon`, `color` fields
   - Templates have `id`, `title`, `category`, `thumbnailUrl` fields
   - All necessary IDs are present and valid

4. **Caching Strategy**:
   - Categories cached for 5 minutes
   - Template previews cached for 5 minutes
   - Frontend maintains `greetingCategoryPreviews` for instant navigation

5. **General vs Business Difference**:
   - **General**: Uses `/api/mobile/greetings/*` endpoints
   - **Business**: Uses `/api/mobile/business-categories/*` endpoints
   - **Separate APIs**: Completely different backend services

### Root Cause Analysis:
The `selectedTemplateId = 'loading'` issue is NOT caused by missing template IDs from the API. The General Category API provides valid template IDs. The issue occurs in the navigation logic when cache misses happen and fallback to `'loading'` placeholder is used.
