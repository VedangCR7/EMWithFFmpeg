Expected: Festival posters should appear when a date is selected
Actual: No images are displayed, only the calendar dates are visible

14. CONCLUSION
================================================================================

The calendar images not showing issue is most likely caused by the backend API 
returning empty data arrays, either due to missing data, authentication issues, or 
endpoint problems. The frontend code appears robust with proper error handling,
but the silent failure mode means users see no feedback when no data is available.

The conditional rendering logic (`selectedDatePosters.length > 0`) combined with 
graceful API error handling creates a scenario where "no data" and "API error" 
both result in the same visual outcome: no images displayed.

Primary focus should be on verifying the backend API endpoint and authentication
flow, followed by implementing proper loading and empty states in the UI.
