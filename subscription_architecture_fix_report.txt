### STEP 1: SUBSCRIPTION API IDENTIFIED

**Function:** `subscriptionApi.getBusinessProfileSubscriptionStatus(profileId)`
**Endpoint:** `/api/mobile/subscription/status?businessProfileId={profileId}`
**Response Structure:**
```typescript
{
  success: boolean,
  data: {
    isActive: boolean,
    status: 'active' | 'expired' | 'cancelled' | 'pending' | 'inactive',
    // ... other fields
  },
  message: string
}
```

**Status Mapping:**
- `'active'` → `'Active'`
- `'expired'` → `'Expired'`
- `'cancelled'` → `'Cancelled'`
- `'pending'` → `'Pending'`
- `'inactive'` → `'Inactive'`

### STEP 2: BusinessProfileContext INTEGRATION

#### Enhanced refreshSelectedProfileFromApi():

**BEFORE:**
```typescript
const freshProfile = profiles.find(p => p.id === currentProfileId);
if (freshProfile) {
  setSelectedBusinessProfileState(freshProfile);
}
```

**AFTER:**
```typescript
const freshProfile = profiles.find(p => p.id === currentProfileId);
if (freshProfile) {
  // Fetch business subscription status
  const subscriptionResponse = await subscriptionApi.getBusinessProfileSubscriptionStatus(currentProfileId);
  const businessSubscriptionStatus = mapStatus(subscriptionResponse.data.status);
  
  // Create enriched profile
  const enrichedProfile = {
    ...freshProfile,
    businessSubscriptionStatus,
  };
  
  setSelectedBusinessProfileState(enrichedProfile);
}
```

#### Enhanced setSelectedBusinessProfile():

**NEW LOGIC:** Fetches business subscription data when profile is manually selected

```typescript
if (profile && profile.id) {
  const subscriptionResponse = await subscriptionApi.getBusinessProfileSubscriptionStatus(profile.id);
  const businessSubscriptionStatus = mapStatus(subscriptionResponse.data.status);
  
  enrichedProfile = {
    ...profile,
    businessSubscriptionStatus: businessSubscriptionStatus || undefined,
  };
}
```
