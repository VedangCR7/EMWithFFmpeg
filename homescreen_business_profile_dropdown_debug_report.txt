STEP 13 — ROOT CAUSE ANALYSIS
============================================================

PRIMARY ROOT CAUSE:
UI elements (userName, userAvatarUri, userInitials) depend on userProfile instead of selectedBusinessProfile

SECONDARY ISSUES:
1. Missing selectedBusinessProfile in useMemo dependencies
2. Profile loading does not update context with stored profile
3. Mixed state usage creates confusion

DETAILED BREAKDOWN:

1. UI DATA SOURCE ISSUE:
   - userName uses userProfile.name instead of selectedBusinessProfile.name
   - userAvatarUri uses userProfile.photo instead of selectedBusinessProfile.logo
   - Dependencies only include userProfile, not selectedBusinessProfile

2. DEPENDENCY ARRAY ISSUE:
   - userAvatarUri: [userProfile] should be [selectedBusinessProfile, userProfile]
   - userName: [userProfile] should be [selectedBusinessProfile, userProfile]
   - userInitials: [userName] should be [selectedBusinessProfile, userProfile]

3. LOADING SYNC ISSUE:
   - loadBusinessProfiles sets selectedBusinessProfileId but not selectedBusinessProfile
   - Context is not updated when stored profile is loaded

4. PRIORITY LOGIC ISSUE:
   - Profile photo should prioritize business profile over user profile
   - Business name should prioritize business profile over user profile
