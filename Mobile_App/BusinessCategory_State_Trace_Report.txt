KEY INSIGHTS
===============================================================================

1. NO TRADITIONAL DROPDOWN:
   - Business categories are displayed as cards, not dropdown
   - Selection triggers immediate navigation
   - No persistent "selected category" state

2. MULTIPLE SOURCES:
   - HomeScreen: User clicks category card
   - My Business Tab: User's business profile category
   - Both end up in PosterPlayerScreen with same param

3. STORAGE STRATEGY:
   - Navigation params (temporary)
   - Business profile context (persistent)
   - API cache (performance)
   - No direct category persistence

4. DATA FLOW:
   - Category name string flows through navigation
   - Used for API calls to fetch posters
   - No complex state management needed
   - Simple and effective architecture
