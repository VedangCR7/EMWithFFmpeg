🔍 MOST LIKELY ROOT CAUSES:

1. TIMING ISSUE - Context not updated before PosterEditor loads
   - PosterEditor might load before HomeScreen context update propagates
   - Route param fallback might be using old/stale data

2. NAVIGATION FLOW ISSUE - Profile selection not triggering navigation
   - User selects profile in HomeScreen
   - But doesn't navigate to PosterPlayer/PosterEditor
   - PosterEditor opened with old/stale route params

3. CONTEXT INITIALIZATION ISSUE - Context loading from AsyncStorage
   - BusinessProfileContext loads from AsyncStorage on mount
   - Might be overriding runtime updates
   - Race condition between AsyncStorage load and HomeScreen selection

4. DEPENDENCY CIRCULARITY - useCallback circular dependencies
   - applyProfileSafely depends on activeBusinessProfile
   - activeBusinessProfile depends on globalSelectedProfile
   - Potential dependency cycle preventing updates
