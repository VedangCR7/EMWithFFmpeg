# Mobile Autopay Fix Report
## Issue Summary
The "Failed to create mandate" error in Business Profile subscription was caused by a missing API function that prevented the mobile app from calling the backend, despite the backend being fully functional.

## Root Cause (Missing createBusinessProfileAutopay Function)
**Critical Issue:** The `createBusinessProfileAutopay` function was accidentally removed from `src/services/subscriptionApi.ts` during recent code changes.

**Impact:**
- `BusinessProfilesScreen.tsx` calls `subscriptionApi.createBusinessProfileAutopay()`
- Function does not exist → `TypeError: subscriptionApi.createBusinessProfileAutopay is not a function`
- Backend never contacted
- Users see "Failed to create subscription mandate" immediately

## Files Modified

### 1. src/services/subscriptionApi.ts
**Action:** Restored the missing `createBusinessProfileAutopay` function
**Location:** Lines 632-691 (before existing `createAutopay` function)

**Function Implementation:**
```typescript
// Create autopay subscription for business profile
async createBusinessProfileAutopay(params: {
  planId: string;
  businessProfileId: string;
  subscriptionCategory: 'BUSINESS_PROFILE';
  customerEmail?: string;
  customerPhone?: string;
}) {
  try {
    const currentUser = authService.getCurrentUser();
    const userId = currentUser?.id;

    if (!userId) {
      throw new Error('User not authenticated');
    }

    console.log('🔄 Creating Business Profile Autopay subscription:', params);

    const payload = {
      ...params,
      userId
    };

    const response = await api.post(
      '/api/mobile/subscription/create-autopay',
      payload
    );

    console.log('📡 Autopay API response:', response.data);

    const data = response.data?.data || response.data;

    const subscriptionId =
      data?.subscriptionId ||
      data?.razorpaySubscriptionId ||
      data?.id;

    if (!subscriptionId) {
      throw new Error('Invalid subscription response from server');
    }

    return {
      ...data,
      subscriptionId
    };

  } catch (error: any) {
    console.error('❌ createBusinessProfileAutopay error:', {
      message: error.message,
      response: error.response?.data,
      status: error.response?.status
    });

    throw new Error(
      error.response?.data?.message ||
      error.message ||
      'Failed to create subscription mandate'
    );
  }
}
```
