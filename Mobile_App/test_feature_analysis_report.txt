BusinessCategoryPoster Interface:
{
  id: string;
  title: string;
  description: string;
  category: string;
  thumbnail: string;
  imageUrl: string;
  downloadUrl: string;
  downloads: number;
  isPremium: boolean;
  tags: string[];
  createdAt: string;
  updatedAt: string;
}

API Endpoint:
- /api/mobile/posters/category/{category}?limit={limit}&categoryId={categoryId}

PosterPlayerScreen Poster Fetching:
- Route parameters provide initial posters
- Additional fetching via businessCategoryPostersApi.getPostersByCategory()
- Template format conversion: BusinessCategoryPoster → Template
- Caching: 5-minute cache duration with Map-based storage

Data Transformation:
```typescript
const templates: Template[] = response.data.posters.map((poster: any) => ({
  id: poster.id,
  name: poster.title || poster.name,
  thumbnail: poster.thumbnail,
  category: poster.category,
  downloads: poster.downloads || 0,
  isDownloaded: poster.isDownloaded || false,
  tags: poster.tags || [],
  languages: [],
  previewUrl: poster.imageUrl || poster.downloadUrl,
}));
```

Poster Display Logic:

- Cloudinary URL optimization
- Progressive image loading
- Language filtering
- Tag-based filtering (for event planners)
