7. ROOT CAUSE ANALYSIS
======================

PRIMARY ISSUE: Inconsistent lineHeight Scaling

The StyleSheet sectionTitle uses:
• Mobile: moderateScale(10) * 1.35
• Tablet: moderateScale(11 * 1.4)

But inline styles override with:
• Mobile: dynamicModerateScale(10 * 1.4)
• Tablet: dynamicModerateScale(11 * 1.4)

PROBLEM IDENTIFIED:
1. StyleSheet uses moderateScale() (static based on initial screen size)
2. Inline styles use dynamicModerateScale() (responsive based on current screen size)
3. Inline styles OVERRIDE StyleSheet values
4. Mobile gets smaller lineHeight relative to fontSize compared to tablet

SPECIFIC CALCULATION DIFFERENCES:

Mobile (typical 375px width):
• moderateScale(10) ≈ 10
• moderateScale(10) * 1.35 ≈ 13.5 (StyleSheet, ignored)
• dynamicModerateScale(10 * 1.4) ≈ dynamicModerateScale(14) (Applied)

Tablet (typical 768px width):
• moderateScale(11 * 1.4) ≈ moderateScale(15.4) (StyleSheet, ignored)
• dynamicModerateScale(11 * 1.4) ≈ dynamicModerateScale(15.4) (Applied)

The issue is that mobile devices get proportionally less lineHeight space compared to the fontSize, especially on smaller screens where the getFontSize() function boosts the font size but the lineHeight doesn't scale proportionally.

----------------------------------------------------------

8. RECOMMENDED FIX STRATEGY
============================

OPTION 1: Fix Inline Styles (Recommended)
Update all sectionTitle inline styles to use mobile-specific lineHeight:
• Mobile: dynamicModerateScale(10) * 1.45 (increase multiplier)
• Tablet: dynamicModerateScale(11 * 1.4) (keep unchanged)

OPTION 2: Remove StyleSheet lineHeight
Remove lineHeight from StyleSheet sectionTitle since inline styles override it anyway.

OPTION 3: Use Consistent Scaling
Apply the same scaling approach (either all moderateScale or all dynamicModerateScale) for both StyleSheet and inline styles.

PREFERRED APPROACH:
Option 1 - Fix inline styles with mobile-specific lineHeight multiplier (1.45 instead of 1.4) to provide adequate descender space for mobile devices while preserving tablet layout.

ANALYSIS COMPLETE
================

Root Cause: Mobile devices get insufficient lineHeight space relative to their fontSize due to inconsistent scaling between StyleSheet definitions and inline style overrides.

Impact: Descender characters (p, q, y, g, j) are clipped on mobile but not tablet due to inadequate vertical space allocation.

Priority: High - Affects readability and professional appearance on mobile devices.
