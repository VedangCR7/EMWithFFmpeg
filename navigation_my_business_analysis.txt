4. CUSTOM TAB BAR IMPLEMENTATION
===============================================================================

File: d:\RSL Solutions\Market_Brand2\src\navigation\CustomTabBar.tsx

The CustomTabBar component overrides the default tab behavior and implements special logic for the "My Business" tab:

```typescript
const CustomTabBar = (props: any) => {
  const { selectedBusinessProfile } = useBusinessProfile();
  
  const handlePosterPlayerShortcut = useCallback(() => {
    const isActive = selectedBusinessProfile?.subscriptionStatus?.toUpperCase() === "ACTIVE";
    if (!isActive) {
      props.navigation.navigate('BusinessProfiles');
      return;
    }
    props.navigation.navigate('MyBusiness');
  }, [props.navigation, selectedBusinessProfile]);

  // In the tab press handler:
  const onPress = () => {
    if (route.name === 'MyBusiness') { 
      handlePosterPlayerShortcut(); 
      return; 
    }
    // Normal tab navigation logic for other tabs
    const event = props.navigation.emit({ type: 'tabPress', target: route.key, canPreventDefault: true });
    if (!isFocused && !event.defaultPrevented) props.navigation.navigate(route.name);
  };
};
```

KEY FINDING:
The CustomTabBar intercepts clicks on the "My Business" tab and implements conditional navigation logic.
