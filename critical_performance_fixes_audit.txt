 # Critical Performance Fixes - Deep Code Audit Report

## Executive Summary

This report provides a comprehensive code audit identifying exact locations for implementing the four critical performance fixes. The analysis traces the entire image loading pipeline from API endpoints to UI components, documenting specific files, functions, and code blocks that require modification.

**Critical Issues Identified:**
1. **Image Size**: 800px thumbnails for 150px displays across multiple components
2. **Preloading Delay**: 200ms setTimeout blocking critical image loading
3. **API Fragmentation**: 6+ separate API calls causing sequential loading
4. **FlatList Over-rendering**: 3+ items rendered simultaneously across all lists

// New function to add
async getAllHomeData(params?: {
  featuredLimit?: number;
  templateLimit?: number;
  categoryLimit?: number;
}): Promise<HomeDataResponse> {
  const queryParams = new URLSearchParams();
  if (params?.featuredLimit) queryParams.append('featuredLimit', params.featuredLimit.toString());
  if (params?.templateLimit) queryParams.append('templateLimit', params.templateLimit.toString());
  if (params?.categoryLimit) queryParams.append('categoryLimit', params.categoryLimit.toString());
  
  const queryString = queryParams.toString();
  const url = `/api/mobile/home/all${queryString ? `?${queryString}` : ''}`;
  
  const response = await api.get(url);
  return response.data;
}
