================================================================================
5. ROOT CAUSE
================================================================================

PRIMARY ROOT CAUSE: handleGreetingCategoryPress intentionally passes a loading placeholder
instead of fetching actual greeting templates before navigation.

LOCATION: HomeScreen.tsx, Line 4719-4726

SPECIFIC ISSUES:
1. selectedPoster.id is hard-coded to 'loading'
2. relatedPosters is always empty array
3. Missing type parameter (should be 'greeting')
4. Missing categoryName parameter
5. No attempt to use available greeting template data

CONSEQUENCE CHAIN:
1. PosterPlayerScreen receives selectedPoster with id: 'loading'
2. currentPoster state initialized with loading placeholder
3. User clicks Next button
4. navigateToPosterEditor passes currentPoster.id ('loading') as selectedTemplateId
5. PosterEditorScreen receives invalid selectedTemplateId

================================================================================
7. WHY IT BREAKS
================================================================================

TECHNICAL BREAKDOWN:

1. **INITIALIZATION FAILURE**:
   - PosterPlayerScreen.currentPoster = { id: 'loading', ... }
   - This is used as the initial state (Line 511 in PosterPlayerScreen)

2. **RACE CONDITION**:
   - PosterPlayerScreen must fetch templates asynchronously
   - User can press Next button before templates load
   - currentPoster.id is still 'loading' when navigation occurs

3. **MISSING VALIDATION**:
   - PosterPlayerScreen doesn't validate selectedPoster before allowing Next button
   - navigateToPosterEditor blindly passes currentPoster.id

4. **INCORRECT PARAMS**:
   - Missing type parameter affects downstream logic
   - Missing categoryName may affect template filtering

DATA FLOW IMPACT:
HomeScreen (id: 'loading') → PosterPlayerScreen (currentPoster.id = 'loading') → PosterEditorScreen (selectedTemplateId = 'loading')

const handleGreetingCategoryPress = useCallback(async (category: { id: string; name: string; icon: string; color?: string }, categoryImage: string | null) => {
  console.log('🎉 GREETING CATEGORY CLICKED:', category.name);

  // Try to fetch greeting templates immediately (like business categories)
  try {
    const templates = await greetingTemplatesService.searchTemplatesFast(category.name, undefined, 10);
    
    if (templates && templates.length > 0) {
      console.log('✅ Found greeting templates:', templates.length);
      
      // Navigate with real template data (like business handler)
      navigation.navigate('PosterPlayer', {
        selectedPoster: templates[0],           // ✅ REAL TEMPLATE
        relatedPosters: templates.slice(1),    // ✅ REAL TEMPLATES
        searchQuery: '',
        templateSource: 'greeting',
        type: 'greeting',                       // ✅ ADD MISSING TYPE
        categoryName: category.name,            // ✅ ADD MISSING CATEGORY NAME
        greetingCategory: category.name,
      });
      return;
    }
  } catch (error) {
    console.warn('⚠️ Failed to fetch greeting templates for category:', category.name, error);
  }

  // Fallback: Navigate with loading state (but include proper params)
  console.log('📋 No greeting templates found, using loading state');
  const thumbnail = categoryImage || '';
  
  navigation.navigate('PosterPlayer', {
    selectedPoster: {
      id: 'loading',
      name: category.name,
      thumbnail: thumbnail,
      category: category.name,
      downloads: 0,
      isDownloaded: false,
    },
    relatedPosters: [],
    searchQuery: '',
    templateSource: 'greeting',
    type: 'greeting',                          // ✅ ADD TYPE
    categoryName: category.name,               // ✅ ADD CATEGORY NAME

  });
}, [navigation]);
