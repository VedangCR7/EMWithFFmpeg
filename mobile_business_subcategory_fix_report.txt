MOBILE BUSINESS SUBCATEGORY FIX IMPLEMENTATION REPORT
====================================================

1. SUMMARY OF THE ISSUE
----------------------
The mobile application was sending the field name "subCategory" to the backend during business registration, but the backend expects "businessSubcategory". This mismatch caused the backend to store the subcategory as an empty value.

2. ROOT CAUSE
------------
- RegistrationScreen.tsx was sending: subCategory: formData.subcategory.trim()
- loginAPIs.ts was using: subCategory?: string in the interface
- Backend expects: businessSubcategory

3. FILES MODIFIED
-----------------
- src/screens/RegistrationScreen.tsx
- src/services/loginAPIs.ts

4. CODE CHANGES MADE
-------------------
