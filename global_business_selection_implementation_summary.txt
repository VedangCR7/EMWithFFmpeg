1. UPDATED BUSINESSPROFILECONTEXT.TSX
-------------------------------------

INTERFACE EXTENSIONS:
```typescript
interface BusinessProfileContextType {
  // Existing
  selectedBusinessProfile: BusinessProfile | null;
  setSelectedBusinessProfile: (profile: BusinessProfile | null) => Promise<void>;
  initializeSelectedProfile: (profiles: BusinessProfile[]) => Promise<void>;
  isLoading: boolean;
  
  // New global business selection state
  selectedBusinessCategory: string | null;
  setSelectedBusinessCategory: (category: string | null) => void;
  selectedBusinessId: string | null;  // Derived from selectedBusinessProfile?.id
}
```

ASYNC STORAGE KEYS ADDED:
- @selected_business_category

NEW STATE VARIABLES:
- selectedBusinessCategory: useState<string | null>(null)

AUTO-SYNCHRONIZATION LOGIC:
- When setSelectedBusinessProfile() is called, automatically updates selectedBusinessCategory from profile.category
- Maintains consistency between profile and category selection

PERSISTENCE:
- Load category from AsyncStorage on context initialization
- Save category to AsyncStorage whenever it changes
- Clear category when profile cache is cleared

PERFORMANCE OPTIMIZATIONS:
- useMemo for context value to prevent unnecessary re-renders
- useCallback for all update functions
- Proper dependency arrays

```typescript
// Validation using global state
const isCategoryMatch = selectedBusinessProfile?.category === selectedBusinessCategory;
const isSubscriptionActive = selectedBusinessProfile?.subscriptionStatus === "ACTIVE";

if (isCategoryMatch && isSubscriptionActive) {
  // Proceed to PosterPreviewScreen
  navigation.navigate('PosterPreview', { ...params });
} else {
  // Redirect to BusinessProfilesScreen
  navigation.navigate('BusinessProfiles');
}
```

6. EDGE CASE HANDLING
---------------------

NO BUSINESS PROFILE SELECTED:
- selectedBusinessProfile === null
- selectedBusinessId === null
- Handle gracefully in validation logic

CATEGORY NOT YET SELECTED:
- selectedBusinessCategory === null
- Can happen when user navigates directly without category selection
- Validation should handle this case

ASYNCSTORAGE NOT YET LOADED:
- isLoading === true
- Show loading indicators or disable actions
- Context manages loading state automatically

USER SWITCHES PROFILE AFTER SELECTING CATEGORY:
- setSelectedBusinessProfile() auto-syncs category from new profile
- Prevents mismatched state
- Maintains data consistency
