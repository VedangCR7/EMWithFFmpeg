### 3. **Root Cause Analysis**

**What Happened**:
1. Merge created conflicts in 18 files due to unrelated histories
2. Conflict resolution used `git checkout --theirs` for most files
3. `--theirs` referred to `subscription-ui-fixes` branch (the second merge parent)
4. This **OVERWROTE** all mobile-app-implement changes with subscription-ui-fixes code
5. The commits are technically in the tree, but their functional changes are gone

**Why This Occurred**:
- `git checkout --theirs` during merge always refers to the "second" branch (`subscription-ui-fixes`)
- `git checkout --ours` would have preserved mobile-app-implement changes
- Manual resolution was needed but automated approach was used
