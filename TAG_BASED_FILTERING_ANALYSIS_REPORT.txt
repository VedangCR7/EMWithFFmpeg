7. ROOT CAUSE SUMMARY
-------------------

🎯 PRIMARY ROOT CAUSES:

1. INCONSISTENT MATCHING ALGORITHMS:
   - Event Planner: Uses substring matching (tag.includes(keyword))
   - Software Company: Uses exact matching (posterTag === categoryTag)
   - Creates unpredictable behavior across categories

2. OVERLY GENERIC TAGS:
   - "it" - Too generic, matches "website", "software"
   - "software" - Causes massive cross-category overlap
   - "development" - Matches multiple category types

3. TAG OVERLAP BETWEEN CATEGORIES:
   - software-dev and custom-software share "software" tag
   - website-dev and software-dev share "development" tag
   - it-consulting "it" tag matches almost everything

4. MISSING TAG NORMALIZATION:
   - No consistent tag format across templates
   - Case sensitivity issues in some places
   - No tag hierarchy or specificity scoring

5. NO TAG VALIDATION:
   - Templates can have any tags
   - No required tags for specific categories
   - No tag quality control
