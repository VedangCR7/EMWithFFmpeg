API USAGE SUMMARY:
============================================================================

BUSINESS CATEGORIES:
- BusinessProfileForm → businessCategoriesService.getBusinessCategories()
- HomeScreen → businessCategoriesService.getHomeBusinessCategories()
- RegistrationScreen → businessCategoriesService.getCategories()

GENERAL CATEGORIES:
- HomeScreen → greetingTemplatesService.getCategories()
- GreetingTemplatesScreen → greetingTemplatesService.getCategories()

IMAGE/POSTER FETCHING:
- PosterPlayerScreen → businessCategoryPostersApi.getPostersByCategory()
- HomeScreen → businessCategoryPostersApi.getUserCategoryPosters()
- HomeScreen → calendarApi.getPostersByDate()
- HomeScreen → homeApi.getFeaturedContent()
- TemplateGalleryScreen → templatesBannersApi.getTemplates()
- GreetingTemplatesScreen → greetingTemplatesService.getTemplates()

IMAGE UPLOAD:
- BusinessProfileForm → businessProfileService.uploadImage()
- ProfileScreen → authApi.uploadProfileImage()

CATEGORY-WISE FETCHING:
- businessCategoryPostersApi.getPostersByCategory(category) → Category-specific posters
- businessCategoryPostersApi.getUserCategoryPosters() → User's business category posters
- calendarApi.getPostersByDate(date) → Date-specific calendar posters
- templatesBannersApi.getTemplates({category}) → Category-filtered templates
- greetingTemplatesService.getTemplates({category}) → Category-filtered greeting templates
